# detect_face_landmarks needs MediaPipe. CPU-only, so it installs anywhere;
# left out of the hard requirements because every other step works without
# it and it pulls a large dependency tree.
#   pip install mediapipe
#
# The Gaussian-splat steps (load_splat / save_splat / render_splat) need
# `plyfile` for PLY I/O — that's it. Rasterisation shells out to the
# brush-splat-render binary (see pipeline/steps/splat.py). body2colmap's
# "splat" extra used to bundle gsplat alongside plyfile and needed a CUDA
# toolchain to build; as of its 24fe424 that extra is plyfile alone,
# because its own SplatRenderer shells out to the same binary. Installing
# plyfile directly is still what this project does:
#
#   pip install plyfile
#
# NOTE the pinned body2colmap commit in docker/Dockerfile: steps/render.py's
# `...+splat` render modes pass a `splat_layer` into
# `Renderer.render_composite`, which only exists from 24fe424 on.
#
# `pointmap_splat` needs `scipy` — ndimage for the mask morphology, and
# sparse/cg for the normal integration. Not listed as a hard requirement
# because it is already a transitive dependency of body2colmap above
# (body2colmap -> pyrender -> scipy), so every environment that can run
# this pipeline at all already has it. It is imported inside functions,
# like every other non-core dependency in pipeline/steps/.

# The web UI (pipeline/webui.py) and the HTTP API (pipeline/api.py) —
# `python -m pipeline.cli ui` serves both on one port. Not a hard
# requirement because every CLI path works without them; the Docker image
# installs them, since serving the UI is what the container does by
# default. fastapi and uvicorn come with gradio, and are named anyway
# because pipeline/api.py imports them itself.
#
#   pip install 'gradio>=5.0,<7.0' 'fastapi>=0.110,<1.0' 'uvicorn>=0.27,<1.0'
